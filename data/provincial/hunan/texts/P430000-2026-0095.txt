关于开展2026年湖南省算力供给方信息登记的通知
各市州工业和信息化局、有关单位:
为深入落实《算力互联互通行动计划》(工信部信管〔2025〕119号)、《湖南省贯彻落实国务院“人工智能+”行动的实施方案》(湘政发〔2025〕7号)及《湖南省算力券补贴政策实施细则》(湘工信信息软件〔2026〕168号)要求,加快构建全省一体化算力统筹调度体系,统一算力接入、服务、运维相关标准,充分释放算力券政策效能,培育壮大算力产业生态,我厅决定组织开展湖南省算力供给方信息登记工作。现将有关事项通知如下:
一、工作目标
面向合规算力服务主体,公开遴选优质算力供给单位,建立省级算力供给资源库,有效破解算力资源分散、供需匹配效率低等问题;将入库单位统一纳入湖南省算力券补贴政策适用范围,推动供需精准对接,引导算力需求方优先使用国产算力资源,激活算力市场需求,提升算力资源利用效率,支撑我省人工智能及相关产业高质量发展。
二、信息登记主体及条件
信息登记主体为境内合法注册、可提供长期稳定算力服务的算力服务运营主体或科研院所,须严格符合《湖南省算力券补贴政策实施细则》规定的基础条件,并满足相应服务能力要求:
(一)基础资质条件
1.具有独立承担民事责任能力,配备保障长期稳定服务的专业技术与运维团队;经营互联网数据中心应取得相应电信业务许可。
2.近三年内无重大违法违规经营记录,未被列入严重违法失信名单,信用状况良好。
3.完成信息登记并按照《湖南省算力调度平台算力资源并网规范》与湖南省算力调度平台对接注册、监测调度及技术适配,遵守平台管理规范。
4.与算力需求方无直接投资与被投资、隶属、共建、产权纽带等影响公平公正市场交易的关联关系。
(二)算力服务能力条件
1.具备可接入省级调度平台的算力资源(含通用算力、智能算力、超算算力等类型),资源权属清晰,可实现统一调度与实时监测。
2.具备完善的服务体系,具有明确的服务内容、服务规范、收费标准及售后保障机制,服务价格处于市场合理区间。
3.具备数据安全、网络安全防护能力与应急保障机制,可保障算力服务稳定、可靠运行。
4.鼓励国产化算力资源优先登记,支持适配国产芯片、国产技术框架的算力服务接入。
三、信息登记范围
本次登记范围涵盖可为企业提供算力资源、算力服务、模型服务及国产化算力适配服务的供给主体,具体包括:
1.各类数据中心、智算中心、超算中心运营单位;
2.具备规模化算力资源的云计算服务、人工智能算力服务运营企业;
3.具备对外服务能力的高校、科研院所算力基础设施运营单位;
4.其他符合条件的算力服务运营主体。
四、信息登记流程
1.注册登记。登记单位登录湖南省算力调度平台(https://csp.hunan-data.com),于2026年8月10日前完成主体注册与实名认证。
2.材料初审。通过省算力调度平台线上对注册登记材料进行初审。初审通过的进入技术对接环节;初核不通过的,平台一次性告知补正要求,登记单位可在5个工作日内补正重报。
3.技术对接与并网测试。通过注册登记初审的单位,严格按照《湖南省算力调度平台算力资源并网规范》(附件3)开展算力资源并网技术对接,完成接口适配、数据连通、调度监测等功能测试,所有登记单位须于2026年8月15日前完成全部并网对接工作。
4.复核与公示。初审通过后另行通知寄送纸质材料,收到通知后请及时寄送纸质材料,寄送地址:湖南省长沙市天心区新韶东路467号9楼901室。省工业和信息化厅对注册登记初审通过且并网测试达标的登记单位进行复核评审,确定本次入库算力供给方名单,并在省工业和信息化厅官网、湖南省算力调度平台同步公示。
5.入库生效。公示无异议的单位,正式纳入湖南省算力供给资源库,成为湖南省算力券补贴政策认可的算力供给方,可通过省算力调度平台对外提供算力服务并参与算力券补贴政策。
五、信息登记材料
具备算力资源供给能力的主体,在信息登记时须提交资质材料,材料清单如下:
1.《湖南省算力调度平台算力供给方信息登记表》(附件1);
2.单位营业执照或事业单位法人证书、法定代表人身份证明复印件;经营互联网数据中心应提供相应电信业务许可证;
3.算力资源材料:算力基础设施情况说明、算力设备清单(含芯片型号、数量、算力规模参数)、算力资源权属证明或授权运营证明;
4.算力服务方案:包含服务内容、服务标准、收费价格体系、运维保障机制、安全防护措施等内容;
5.登记材料真实性与算力资源纳管承诺书(附件2);
6.材料提交日期前近三个月内的“信用中国”网站(www.creditchina.gov.cn)的查询信息截图(包括失信被执行人查询截图、重大税收违法失信主体查询截图),需显示查询日期。若服务提供方未被列入上述网站,说明其未被列入该网站并加盖公章;
7.其他材料(如绿色数据中心认证、网络安全等级保护备案证明、服务案例等)。
六、有关工作要求
1.本次信息登记采用电子及纸质材料报送方式,先行在省算力调度平台完成注册登记初审及并网测试达标,初审通过后另行通知寄送纸质材料至省工业和信息化厅进行复核评审。

‏	•	总则


1.1目的
为统一省域算力调度平台网关接口标准，规范接口设计、开发、发布、调用、安全、日志、版本与运维管理，保障数据共享交换稳定、安全、高效、兼容，明确资源提供方与资源需求方责任义务，特制定本规范。
本规范适用于所有接入省域算力调度平台网关的算力中心、业务系统、应用模块、接口开发方、调用方、运维方及相关管理活动。

1.2 接口类型
平台支持主流接口实现方式（REST接口），所有接口返回数据统一采用JSON 格式，发布服务时须明确标注接口实现类型。
REST 风格接口服务消息封装，遵循HTTP标准协议。

1.3 接口请求方式
接口仅支持GET、POST两种请求方式，严格按照业务场景区分使用：
GET 请求：适用于资源需求方从资源提供方获取信息、查询数据的场景。
POST 请求：适用于资源需求方向资源提供方提交信息、上报数据的场景。

1.4 接口应答内容
接口接收到有效请求后，统一返回标准化应答结构，包含状态标识与业务数据，应答字段定义如下：
statusCode：执行结果状态码；200表示执行成功，非200表示执行失败，具体异常编码见接口错误编码表。
msg：执行结果描述信息；执行失败时需返回详细错误原因
result：接口返回的核心业务数据
records: 列表数据（分页场景必填）
count：数据总记录数（分页场景必填）
page：数据总页数（分页场景必填）
size: 数据每页数量（分页场景必填）

1.5 接口安全规范

① 传输安全：
所有接口必须使用HTTPS 加密传输，禁止使用 HTTP。
接口服务端启用TLS 1.2 及以上版本。

② 身份认证：
必须校验appkey 合法性，未分配、无效、过期 appkey 拒绝调用。
敏感数据接口必须增加username/appkey 身份校验。

③ 权限控制：
未授权接口的statusCode字段直接返回10003，表示用户权限不足。

④ 防攻击：
接口启用限流：单IP / 单 appKey 限制调用频次。
防止重放攻击：支持timestamp + nonce + sign 签名机制。
防止SQL 注入、XSS、参数篡改：参数必须校验与过滤。

⑤ 数据安全：
数据传输与存储遵循国家网络安全、数据安全、个人信息保护相关法规。
涉密数据不得通过普通接口明文传输。

‏2、获取Token接口（用于后续节点注册和数据上报相关接口）
说明：获取平台的Token接口，在后续调用其它接口时，需要在Header参数中传入。注意Token是有有效期的，默认是72小时有效。调用该接口时需要在参数头中对所有参数使用md5映射后，得到sign属性放到Http Header中，用于校验参数的正确性。获取sign属性方法：
	•	参数排序：将所有请求参数按照参数名的字母顺序（ASCII码升序）进行排序。
	•	拼接字符串：将排序后的参数与对应值用等号 = 连接，参数之间使用 & 连接。若某参数值为空，则等号后保留空值。 示例：排序后参数为 appkey、nonce、timestamp、username，值分别为 abc、1234567890abcdef、1777434720、admin，则拼接结果为 appkey=abc&nonce=1234567890abcdef&timestamp=1777434720&username=admin。若 有nonce的值为空，则结果为 appkey=abc&nonce=&timestamp=1777434720&username=admin。
	•	生成签名：对上述字符串计算 MD5 值，得到 sign 值，并放入 HTTP Header 中。空值示例：appkey=abc&nonce=&timestamp=1777434720&username=admin 的 MD5 值为00D4AF3DB388771EF38887B451F13CB1。 
	•	生成sign字符串中的属性顺序一定要按照每个接口中表格列出的属性顺序来生成，如appkey、nonce、timestamp和username顺序不能发生变化，否则校验不过。

重要说明：
	•	Token 有效期为 72小时，后续接口调用需在 Header 中携带该 Token。
	•	参数排序必须严格按照字母顺序，否则签名校验将失败。如appkey、nonce、timestamp和username顺序不能发生变化，否则校验不过。
	•	Token是后续进行节点信息注册、节点资源使用数据上报的重要凭证和参数。

参考代码（java语言，其他语言根据java示例需要自行开发）：

public static String generateSign(Map<String, Object> params) {     // 1. 参数排序：按照参数名字母顺序（ASCII码升序）排序     List<String> sortedKeys = new ArrayList<>(params.keySet());     Collections.sort(sortedKeys, String.CASE_INSENSITIVE_ORDER);      // 2. 拼接字符串：参数与值用=连接，参数之间用&连接     StringBuilder sb = new StringBuilder();     for (int i = 0; i < sortedKeys.size(); i++) {         String key = sortedKeys.get(i);         Object value = params.get(key);         String valueStr = value != null ? value.toString() : "";                  if (i > 0) {             sb.append("&");         }         sb.append(key).append("=").append(valueStr);     }      // 3. 生成MD5签名     return md5(sb.toString()); }
